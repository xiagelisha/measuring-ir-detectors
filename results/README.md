# Historical experimental results

This directory preserves the original run records and analysis outputs. For the
statistical analysis package, use [revision_r2](../revision_r2/README.md), which
includes the unchanged 95 run-level records, current source-data map and new
training/test uncertainty analyses.

The preceding descriptions and figure numbers are retained in
[README_historical.md](README_historical.md) for provenance. Interpretations such
as class reallocation or architectural-module effects in that historical document
are historical interpretations. C3/C4 records now serve as supporting
reporting examples. No original measurements were replaced.
